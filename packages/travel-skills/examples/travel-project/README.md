# Travel Project Example

This workspace showcases an AI agent project using the `travel-skills` pack connected to the Ultimate Travel MCP Server.

## How it works

1. **Travel Skills Installed**: The 6 travel skills are placed in `.agents/skills/` to provide reasoning rules for budgeting, safety, crowd avoidance, and source verification.
2. **MCP Server Connected**: The AI client (Antigravity, Claude Code, Cursor) connects to the Ultimate Travel MCP Server (local or remote) to query travel data.
3. **Trip Planning Execution**: Prompts like `trip-request.md` are executed with high precision and realistic pacing.
