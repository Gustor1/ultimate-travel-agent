# Open Data Licensing & Attribution Policy — `ultimate-travel-agent`

**Phase:** Phase 10 — Keyless Public Data Integrations  
**Status Date:** 2026-09-13  
**Applicability:** All local CLI runs, Web UI displays, MCP tool responses, and exported Markdown dossiers  

---

## 1. Regulatory Context & Compliance Statement

`ultimate-travel-agent` leverages open public datasets to provide real-time travel context without requiring proprietary API keys. Open data licenses impose strict legal requirements regarding **credit, license notice, and attribution preservation**.

In accordance with these licenses:
- All tool outputs and programmatic models include explicit `attribution`, `source_url`, and `retrieved_at` fields.
- The Web UI presents persistent attribution links in its application footer and within dynamic result cards.
- The final synthesized trip dossier (`dossier.md`) includes an itemized Sources & Attribution section.

## 3. Attribution Display in User Interfaces

### 3.1 Web Interface (FastAPI + HTML5)
The Web UI (`src/ultimate_travel_agent/web/static/index.html`) embeds a persistent open data credits block in the global footer:
```html
<div class="open-data-credits">
  <p>Live Keyless Open Data Providers:
    <a href="https://open-meteo.com/" target="_blank" rel="noopener">Open-Meteo (CC BY 4.0)</a> &bull;
    <a href="https://www.ecb.europa.eu/" target="_blank" rel="noopener">European Central Bank (ECB)</a> &bull;
    <a href="https://en.wikivoyage.org/" target="_blank" rel="noopener">Wikivoyage (CC BY-SA 4.0)</a> &bull;
    <a href="https://www.openstreetmap.org/copyright" target="_blank" rel="noopener">&copy; OpenStreetMap contributors (ODbL)</a>
  </p>
</div>
```

### 3.2 MCP Tool Programmatic Responses
Every keyless tool return format wraps items in a `ProviderSearchResult` dictionary:
```json
{
  "provider": "open_meteo",
  "mode": "live",
  "source_url": "https://api.open-meteo.com/v1/forecast?latitude=41.38&longitude=2.17...",
  "attribution": "Weather data by Open-Meteo.com under CC BY 4.0 (https://open-meteo.com/)",
  "verification_level": "cross_checked",
  "cache_status": "hit",
  "result_status": "live",
  "items": [...]
}
```

### 3.3 Markdown Dossier Synthesis (`reporter.py`)
The final trip synthesis generated by Wave 5 `travel-orchestrator` appends an explicit data lineage table:
- Listing each retrieved endpoint
- Specifying the retrieval timestamp (`retrieved_at`)
- Providing the verbatim license notice and upstream URL
